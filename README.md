# eClass

A real-time web-based classroom and learning
management platform.

## Overview

eClass enables teachers and students to interact
through virtual classrooms.

## Core Features

- Role-based access control
- Teacher and student dashboards
- Classroom management
- Pre-registered student enrollment
- Live audio/video communication
- Collaborative whiteboard
- Real-time classroom events
- Attendance management

## Technology Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- MySQL
- Prisma ORM

### Real-time Infrastructure
- Socket.IO
- WebRTC
- LiveKit

### DevOps
- Git
- GitHub
- Docker
- GitHub Actions

## Project Structure

- frontend: React application
- backend: Express API
- infrastructure: deployment and Docker
